====================================================
           A2 HCR - 3D NAVIGATION RADAR
====================================================

A modern, lightweight, non-intrusive 3D HUD Navigation Radar overlay for locating and navigating to Hidden Cubes in Aion 2 in real time.
Zero memory hooking, zero DLL injection, zero game file modification. 100% passive network packet inspection.

----------------------------------------------------
PREREQUISITES & INSTALLATION (READ FIRST)
----------------------------------------------------

1. INSTALL PYTHON (REQUIRED):
   - Python 3.10, 3.11, 3.12, or 3.13 (Tk 9 supported).
   - Download from https://www.python.org/downloads/
   - IMPORTANT: During installation, make sure "Add Python to PATH" is checked!

2. INSTALL NPCAP (REQUIRED FOR PACKET CAPTURE):
   - Like popular DPS meters, A2 HCR operates strictly by sniffing network traffic.
   - Sniffing requires the Npcap packet capture library on Windows.
   - Download Npcap from: https://npcap.com/#download
   - IMPORTANT: During Npcap setup, check "Install Npcap in WinPcap API-compatible Mode".

3. INSTALL PYTHON DEPENDENCIES:
   - Double-click "Install_Requirements.bat".
   - This automatically installs: scapy, lz4, psutil.

4. LAUNCH THE RADAR:
   - Double-click "Start_Radar.bat" (runs as Administrator for network sniffing).
   - The radar overlay appears on your screen and begins scanning automatically.

----------------------------------------------------
HOW IT WORKS & MOVEMENT SYNCHRONIZATION
----------------------------------------------------

* DPS-METER STYLE PASSIVE PACKET INSPECTION:
  A2 HCR analyzes incoming network packets on TCP ports 13328 / 13320.
  It does not touch game memory or files, making it completely undetectable and safe.

* SERVER MOVEMENT NETCODE NOTE (VERY IMPORTANT):
  In Aion 2, server netcode optimizes network traffic by not broadcasting continuous ground walking packets.
  Instead, true server-verified 3D coordinates (opcode 0x382a) are broadcast during active movement actions:
  - Opening wings / Gliding
  - Dashing (Shift / Dash)
  - Jumping (Space bar)
  - Casting skills

  THEREFORE: When a Hidden Cube is detected nearby, continuously JUMP, DASH, or TAP WINGS
  to update your exact distance and directional arrow in real time!

----------------------------------------------------
3D HUD DISPLAY & DIRECTIONAL ARROW
----------------------------------------------------

* 3D DIRECTION ARROW & COLOR CODING:
  When a Hidden Cube is in range (up to 150m), an interactive 3D arrow points directly toward the cube:
  - RED ARROW: Far distance (> 50 meters away).
  - YELLOW / ORANGE ARROW: Medium distance (< 50 meters away).
  - GREEN ARROW: Close proximity (< 15 meters away - you are right next to the cube!).

* LIVE DISTANCE & ELEVATION INDICATOR:
  - Distance is shown in large bold text (e.g. "32 m").
  - Vertical box shows elevation relative to your character:
    * "↑ ABOVE BY 8m" (Cube is on a cliff, rooftop, or tree above you)
    * "↓ BELOW BY 5m" (Cube is down in a valley, pit, or under a ledge)
    * "═ LEVEL (SAME HEIGHT)" (Cube is on the same ground level)

* STANDBY SWEEPER:
  When no cube is currently nearby, the radar displays a smooth rotating radar sweep scanner line while searching.

----------------------------------------------------
SETTINGS & CUSTOMIZATION (GEAR ICON ⚙)
----------------------------------------------------

Click the ⚙ icon on the top header to configure:
1. RADAR SCALE / SIZE:
   - Scale slider from 75% to 150% to make the overlay smaller or larger according to your screen resolution.
2. RADAR OPACITY:
   - Transparency slider from 20% to 100%.
3. CHARACTER NAME (OPTIONAL):
   - You can enter your character name to strictly bind your Entity ID in crowded areas.
   - If left blank, the radar automatically binds to your entity on your first jump/dash (0x382a).
4. AUDIO ALERTS:
   - Enable/disable sound notifications when a cube spawns.
   - 5 audio sound profiles (Radar Ping, Classic Beep, Double Chime, Sci-Fi Pulse, Subtle Click).
   - Live volume slider and test sound button.

----------------------------------------------------
CONTROLS:
- Click and drag anywhere on the overlay to move it across your screen.
- Click ⚙ to open settings.
- Click ✕ in the top-right corner to exit.
